# Bestia Shop

Tienda demo de indumentaria xeneize con catálogo, selección de talle y carrito de compras.

## Probar localmente

Desde esta carpeta, ejecutá:

```sh
python3 -m http.server 8000
```

Después abrí <http://localhost:8000>. El carrito se guarda en el navegador; los productos y precios son de demostración y no hay pagos ni pedidos reales.
